# Закрытые вопросы аудита (блокеры)

Журнал решений по блокерам аудита. Дата последнего обновления: 2026-10-31.

Из 45 блокеров **41 закрыт** (решения ниже), **4 перенесены в открытые вопросы** (раздел «Незакрытые блокеры из аудита» в [99_открытые_вопросы.md](../99_открытые_вопросы.md), пункты 11–13). Сами аудиты лежат в `аудит_{N}_….md`, сводка по остальным приоритетам (средние, низкие, опциональные) в [аудит_итог.md](аудит_итог.md).
