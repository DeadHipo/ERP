## Как работать

- Две линии, «Трек» и «Деньги», независимы; шаги внутри линии строго по порядку. M5 идёт после T3.
- Если правки пересекаются по файлам, пишет один агент. Если нет — можно параллельно в worktree.
- Шаг = исполнитель → независимый ревьюер (только diff и SPEC) → твой DoD → коммит.
- Равенство со старым ответом проверяется тестом до перевода экрана. Чини новое, старое не трогай.
- `Hook timed out` значит, что машина занята. Перезапусти последовательно (см. `packages/backend/tests/CLAUDE.md`).
