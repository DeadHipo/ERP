# Правила для каждого субагента совета

Общая часть брифа. Оркестратор даёт её каждому участнику вместе с ролью, уровнем, списком файлов и форматом ответа.

## Что мы делаем

Совет проектирует (без кода) более простую и понятную структуру модулей royalty ERP музыкального лейбла. Задание —
`docs/идеи/модули_и_документы/spec.md`, снимок фактов — `факты.md` там же, роли — `роли.md`. Корень репозитория:
`/Users/nearlydeadhipo/Desktop/0to8/ERP`. Общая картина проекта: `CLAUDE.md` в корне и `docs/agents/01_big_picture.md`.

## Жёсткие правила

1. **Писать можно только свой файл** (путь назван в брифе) внутри `docs/идеи/модули_и_документы/`. Никаких других
   файлов не создавать и не менять: ни в `packages/`, ни в `docs/`, ни миграций, ни скриптов.
2. **База — только SELECT.** PostgreSQL:
   `docker exec -e PGOPTIONS='-c default_transaction_read_only=on' -i royalty-erp-postgres-1 psql -U erp -d erp -c "…"`.
   ClickHouse: HTTP на `localhost:8123`, база `believe`, логин и пароль в `.env` корня (`CLICKHOUSE_USERNAME`,
   `CLICKHOUSE_PASSWORD`); только `SELECT`. Никаких INSERT / UPDATE / DELETE / DDL. Живая организация одна.
3. **Не запускать** тесты, e2e, dev-серверы, скрипты загрузки, миграции. Не коммитить, не пушить, не трогать git.
4. **Личные данные не копировать:** юридические имена авторов и людей, содержимое договоров, реквизиты. Псевдонимы
   артистов и названия лейблов можно. Числа и счётчики можно.
5. **Расчёт священен:** `calculation.ts`, `facade/layers/*`, `owner-scope.ts`, математика `balance.ts`, балансы,
   payroll, срезы, сверка выплат не должны менять числа. Если твоя мысль меняет числа — скажи это прямо.
6. Решения со знаком ⚠ в `docs/agents/03_decision_index.md` ждут владельца: не решать за него.
7. Провайдеры (PandaDoc, final_index) и соседние проекты в `/Users/nearlydeadhipo/Desktop/0to8` — только читать, ничего
   не отправлять и не создавать.
8. Других участников совета не читать, если бриф прямо не велит (папка `консилиум/` — чужие ответы).
9. Цифры — из кода и SELECT, а не на глаз. У утверждения о коде — путь к файлу (и строка, если есть).
10. Язык ответа — русский, коротко и по делу. Финальное сообщение оркестратору: одна-две строки («готово, файл …»).
