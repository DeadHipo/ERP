# маркетолог / руководитель: приёмка

**Вердикт:** принимаю с замечанием

**Что из моего первого голоса закрыто**
1. Ничего моего не сломано: `ads` остаётся отдельным модулем с таблицей `expenses` (Р2), без документа на расход, расчёт не меняется (Р5, метрика 6: закрытые зоны 0, числа 0).
2. Не добавлено ни новой страницы, ни «получателя», ни договора на расход: все мои «усложнения» обойдены.

**Что не закрыто или отложено**
1. Отдача (доход трека против рекламы) — моя главная боль. Р26 называет «отдачу рекламы» экраном поверх расчёта и откладывает после чистки, без срока. Честно сказано, но слово «отдача» стоит рядом с «реестром выплат» как один из экранов, хотя это единственный пункт про ROI.
2. Сигнал «расходы за месяц не заведены / расход без сплита» и подсказка «кто понесёт» до сохранения: в итоге не упомянуты. Р23 (одна очередь) мог бы их принять, но реклама в списке источников очереди (C, сигналы, чек-лист) не названа.
3. Процент возврата по умолчанию из договора или лейбла: не затронут.

**Замечание**
Не блокер: вреда нет. Прошу в Р23 явно вписать рекламу в очередь («расход без сплита», «месяц без расходов»), а в Р26 — отдачу рекламы отдельной строкой с первой целью после чистки. Иначе упрощение формально выигрывает, а мой сценарий 5 остаётся ручным.
