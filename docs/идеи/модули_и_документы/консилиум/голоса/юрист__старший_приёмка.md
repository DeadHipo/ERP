# юрист / старший: приёмка

**Вердикт:** принимаю с замечанием

**Что из моего первого голоса закрыто**
1. Нельзя ломать: правило «нет утверждённого документа, значит деньги ждут в C», неутверждаемый `assumption`, `X-Operator`, неизменный снимок. Р16 и Р25 это сохраняют; закрытые зоны не открываются (метрика 6).
2. «Подписанный договор остаётся там, где лежит, и не дублируется в полях ERP»: Р16 (модуля документов нет, источник по `file_ref`), Р17 (статус подписи не храним).
3. Усложнений, которых я боялся (новый вид документа, модуль с очередями), нет. Р11 даже убирает пару «договор + документ».

**Что не закрыто или отложено**
1. Срок, расторжение, холд на ISRC или долю (В8). Честно названо отдельной целью. Но сегодня «право истекло» система по-прежнему не знает.
2. Статус из PandaDoc как данные: отказано (Р17). Расхождение видно только в пробном прогоне импорта, между прогонами его нет. Сказано честно.
3. Путь «выплата → основание» (сценарий С7, шаг 4): обещан, но решение Р16 даёт только метку источника и ссылку. Что снимок выплаты сам показывает документы, ни одно Р не говорит.

**Замечание**
Р16/Р17 и С7 шаг 4. Нужно прямо записать: снимок выплаты показывает документы, на которых стоят её суммы (через существующий `GET /documents/:id/uses`), либо убрать шаг 4 из обещаний. Р11: перед переходом сверить 247 строк сплита (В4б), иначе утверждённые документы без записи договора остаются «ждущими» молча. Просмотр без права `approve` сохранён, это хорошо.

**Что было непонятно**
«Закрытая зона», «проекция», «книга», «срез». Не сразу ясно, что «признак договора» (`is_contract`) не равен виду документа.
