**Замечание**
- Р8 и В6(б): вместе с таблицами v1 тихо уходит условие одного владельца «по типу операции», под v2 оно не действует (D-187). Это деньги паблишинга. Прошу не удалять v1 без явного ответа владельца по D-187. Итог так и рекомендует, но в Р8 это условием не записано.
- Р21: где человек выбирает, какого из двух получателей оставить, не сказано (замечание оформителя 6). Нужна явная деактивация до слияния, записанная в D-записи.
- Р23: в первую версию очереди включить колонки «причина по порядку ворот», «кто снимает», «срок».
