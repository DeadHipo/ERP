## 2. Что считаю ошибкой

**Архитектор: «слить `contracts` в `documents` нельзя без изменения чисел».** Неверно.
- Из 11 документов вида contract / label_decision без строки договора владелец есть у 5. Ни один из этих 5 не стоит ни в `split_shares`, ни в `participations`, ни в `label_rules`, ни в `operations` (SELECT: 0 ссылок).
- У остальных 6 владельца нет, поэтому подтвердить владельца они не могут. Ссылки на них (40, 28, 30 и 2 участия, 1 правило) проверяют вид по `SPLIT_DOCUMENT_KINDS`, а вид не меняется.
- Значит, достаточно перед миграцией перевести эти 5 документов в вид `other`, и числа не изменятся.
- Признак договора при этом не может быть «`number` не пуст»: номер пуст у 345 из 818 договоров. Признак: вид из `CONTRACT_DOCUMENT_KINDS` и есть `owner_id`.

**Архитектор: оставить `track_labels` ради «операторских интервалов».** Их 0. Ручную поправку (D-172) за всё время не использовали ни разу. Хранить таблицу ради возможности, которой не пользуются, — это мёртвый груз по §3.

**Архитектор и менеджер: «закрытых зон 2 файла, только импорт».**
- Обе строки (`calculation.ts:7` и `layers/writer-parts.ts:3`) импортируют из пути `../modules/publishing`.
- Если бывший pubv2 будет называться `publishing` и экспортировать `parseSongwriters` и тип `PublishingService`, текст этих строк не изменится.
- Тип сегодня — форма v1, которую `pubv2-source.ts:121` наследует через `Object.create(publishing)`. Его можно переложить в новый модуль. Это спор, который решает код (§4, утверждение 1).

## 3. Как меняю своё предложение

- **Снимаю риск 1 и рекомендацию «подтвердить двух владельцев».** По умолчанию 5 договорных документов с владельцем без строки договора переходят в `other`, и числа не меняются. Подтвердить этих двух владельцев — отдельный вопрос владельцу с теневым прогоном (это изменение чисел из C в B).
- **Добавляю удаление `owners.contract_artists`** (809 строк, 433 псевдонима).
  - Его читает только `contractsOfOwner` (`modules/owners/service.ts:955`), то есть показ: `owner-view.ts:107`, `artist-view.ts:177`, `aggregates.ts:506`.

  - Изменится показ у 14 псевдонимов, деньги не изменятся.
- **Добавляю удаление `owners.artist_tracks`** (довод минималиста подтверждён SELECT).
- **Беру у архитектора** перенос `payees`, `holds` и `payout_answers` при слиянии. Сегодня таких строк 0, числа не меняются.
- **Оставляю вопреки критике:**

  - `label_accounts` в labels без изменений;
