# Узлы графа: входы, выходы, параметры

Дата: 2026-11-04. Основа для демо (`index.html`, `cases.js`). Соответствует решениям консилиума Р1–Р10
(`../консилиум/итог.md`). Каждый узел = один вид слоя из `facade/layers/`. Вход «из ctx» — что узел спрашивает у
контекста (один снимок модулей), «из состояния» — что берёт из `UnitState`, «параметры правила» — поля строки в базе,
которыми узел параметризован.

## Общие входы всего графа (контекст одного расчёта)

| Вход | Откуда | Что это |
|---|---|---|
| юнит | ClickHouse `believe.units` | `account, isrc, upc, reportingMonth, salesMonth, labelName, net` |
| дата правил | `reportDate(unit)` | 1-е число отчётного месяца |
| `labelOf(строка, дата)` | модуль labels | лейбл записи, наш лейбл, правило саблейбла на дату |
| `knownPairs` | модуль owners | пары ISRC\|UPC из треков |
| `splitAt(isrc, дата)` | модуль splits (индекс) | сплит, строки `{artistId, percent, documentId}`, документ сплита |
| `participationsAt(isrc, дата)` | модуль splits (индекс) | участия `{id, artistId, percent, base, fundedFrom, fromArtistId, documentId}`, отсортированы по виду |
| `artistIndex` | модуль owners | псевдоним → владелец, слияния (`canonical`) |
| `documentStatus / documentKind` | модуль owners | approved / not_approved / missing; `assumption` |
| `confirmedOwners` | модуль owners | подтверждённые владельцы |

## Узлы

| # | Узел (слой) | Из ctx | Из состояния | Параметры правила | Выходы (рёбра) | Остаток |
|---|---|---|---|---|---|---|
| 0 | `label-of-record` | `labelOf(labelName, дата)` | `unit.labelName` | алиас → лейбл; правило: `percent`, `recipientArtistId`, `documentId`, период | нет рёбер: ставит `ourLabelId`, `rule`, `labelShareCategory` | — |
| 0' | `perimeter` | `knownPairs` | `isrc`, `upc` | — | одно ребро `net → c:no_isrc` или `c:unknown_pair`; `stopped` | — |
| 1 | `off-the-top` (`net`) | `participationsAt` → только `fundedFrom = top` | `unit.net` | `percent` (от net), `documentId`, период | `net → artist:T` по участию | `net → scaledNet` = net − Σ top |
| 2 | `split` (`scaledNet`) | `splitAt` | `scaledNet` | строки `percent` (от scaledNet), документ строки или сплита, период | `scaledNet → row:X` по строке (percent 0 пропускается) | `scaledNet → labelShare` = scaledNet − Σ строк; без сплита — целиком |
| 3a | `carve:pool` (`row:*` → `pool`) | `participationsAt` → `artist_pool` | строки `row` | `percent` от **net** (`base = net`), документ | `row:X → pool` (draw, пропорционально строкам), `pool → artist:M` | у `pool` остатка нет: Σ draw = Σ выдано; при нехватке цели масштабируются, shortfall |
| 3b | `carve:artist_share` (`row:X`) | `participationsAt` → `artist_share` (`fromArtistId`) | строка `row:X` после пула | `percent` от **строки** (`base = bucket`), документ | `row:X → artist:E` | остаток строки → `row:X → artist:X` (считается в конце) |
| 3c | `carve:label_share` (`labelShare`) | `participationsAt` → `label_share` | `labelShare` после сплита, `unit.net` | `percent`, `base` (`net` или `bucket` = доля лейбла), документ | `labelShare → artist:P` | — (общий остаток см. 3d) |
| 3d | `sublabel` (`labelShare`) | — | `rule`, `labelShare` после 3c, `labelShareCategory` | `rule.percent` от остатка доли лейбла, документ правила | `labelShare → artist:S` | `labelShare → ours` или `→ c:label_unmapped` |
| 4 | `categorise` | `documentStatus`, `documentKind`, `artistIndex`, `confirmedOwners` | все аллокации, `rule` | — | нет рёбер: ставит `category`, `reason`, `assumption` на рёбрах в `artist:*` | — |

Правило остатка: ровно один выход узла считается вычитанием. У `net` — `scaledNet`; у `scaledNet` — `labelShare`;
у `row:X` — `artist:X`; у `labelShare` — `ours`/`c:*`; у `pool` остатка нет.

## Что видит каждый узел и чего не видит

- Узел видит только корзину, из которой берёт, и свои правила. `label_share` не знает про pool; `sublabel` видит
  `labelShare` уже после `label_share` (поэтому Q11 — вопрос порядка).
- Узел не видит других юнитов: фиксированные суммы «в месяц» — не узел (`../README.md` §6).
- Процент всегда от явной базы: `net` (top, pool, label_share с `base = net`), `scaledNet` (строки), строка
  (artist_share), доля лейбла (label_share с `base = bucket`, sublabel). На ребре это поле `base`.
