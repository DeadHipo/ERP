Идея (не менять): каждый источник и справочник — отдельный модуль, модули не знают друг о друге. Фасад ничего не хранит: каждый раз с нуля собирает данные и считает (по владельцу, треку, лейблу). Начислений нет, есть снимок выплаты. A = B + C + наша доля по каждому источнику и месяцу. Деньги назначает документ или справочник. Ключ записи — ISRC (с UPC, где нужно). Имя артиста и название трека ключом не бывают: они повторяются. Нет ISRC — строка в C на ручной разбор, не приоритет.

Простота — главный критерий. Модуль умеет одно, описание — три предложения в его CLAUDE.md. Например, «документы» принимают документ, проверяют валидность, провайдер (PandaDoc) за интерфейсом; «лейблы» знают лейблы, саблейблы, импринты. Модули денег не считают. Расчёт в фасаде — цепочка слоёв: каждый слой — отдельная функция со своим тестом, порядок задан в одном месте. Кейс, закрываемый данными, — без нового поля.
